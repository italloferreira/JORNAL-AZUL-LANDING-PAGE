## 📌 Sobre o projeto

O **Jornal Azul Landing Page** é um projeto front-end que simula um portal de notícias esportivas.  
A aplicação foi desenvolvida com foco em **estruturação de páginas**, **interatividade com JavaScript**, **manipulação do DOM** e **persistência de dados no navegador**, sem uso de backend.

A proposta principal do projeto é permitir que o usuário:

- visualize notícias em uma página inicial com destaque;
- cadastre novas notícias por meio de um formulário;
- acesse a página individual de cada notícia;
- tenha uma experiência de navegação simples, direta e organizada;
- explore páginas voltadas para tabelas esportivas dentro da proposta do portal.

---

## 🎯 Objetivo

Este projeto demonstra minha capacidade de desenvolver uma aplicação front-end funcional utilizando apenas tecnologias base da web, com foco em:

- organização de interface;
- separação de páginas e responsabilidades;
- manipulação de dados no lado do cliente;
- uso de armazenamento local (`localStorage`);
- renderização dinâmica de conteúdo;
- navegação entre páginas com parâmetros de URL.

Mais do que uma landing page visual, o projeto funciona como uma pequena base para evolução de um portal esportivo mais completo.
